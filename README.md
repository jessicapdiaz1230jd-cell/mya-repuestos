# M&A Repuestos

Sistema de gestión para servicio técnico de celulares.

## Funciones principales

- Registro de clientes y equipos.
- Órdenes de servicio con número consecutivo.
- Diagnóstico, reparación y estados de seguimiento.
- Fotografías de recepción y entrega.
- Cobros, saldos, formas de pago y garantías.
- Historial de servicios por cliente, teléfono e IMEI.
- Logo reemplazable desde la configuración.
- Interfaz adaptable a celular, tableta y computador.

## Propiedad y privacidad

Este repositorio conserva el código de la aplicación. Los datos de clientes, fotografías, contraseñas y registros operativos se almacenan por separado y nunca deben subirse al repositorio.

## Puesta en producción independiente

La aplicación está preparada para usar una base de datos D1 y almacenamiento R2. Para publicarla fuera de ChatGPT se deben crear estos recursos en una cuenta de Cloudflare de propiedad de M&A Repuestos, configurar autenticación propia y desplegar el sistema como aplicación web instalable.
